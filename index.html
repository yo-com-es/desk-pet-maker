Exportar

Hornea la animación actual (la que esté sonando ahora) dentro de un .glb nuevo, junto con el pelo pintado y la piel pintada — el archivo queda listo para que cualquiera lo abra en Blender, Unity, Godot, o donde sea, sin necesitar este programa.

Mapeo de huesos

Asigna qué hueso hace qué. Así el ciclo de caminar/correr funciona con cualquier rig, tenga nombres claros o no.

Pintar como lienzo

Estilo Mecca Chameleon / Mii: el cuerpo es un lienzo en blanco. No se toca el modelo base ni el rig, solo la textura.

Pinceles — el primero (●) es el círculo normal; sube el tuyo con el botón +.

Pelo pintado a mano

Igual que en el video: dibujas el pelo sobre un lienzo transparente, lo no pintado se recorta solo, y el resultado queda pegado al frente del modelo — usando la forma del modelo mismo, NO un hueso, así no importa cómo esté armado el esqueleto de cada personaje.

Dale al botón y luego haz clic directo sobre el modelo, en el punto exacto donde quieres que quede el pelo — queda pegado ahí mismo, siguiendo la superficie, como una calcomanía.

Pinceles — el primero (●) es el círculo normal; sube el tuyo con el botón +. (No lee archivos .sut nativos de SAI, pero si exportas/capturas tu pincel como imagen PNG funciona igual.)

Ajuste fino de posición

Pinta primero, luego dale a "Poner/actualizar pelo" para pegarlo — puedes seguir pintando y volver a darle al botón para refrescarlo. El punto de partida ya lo calcula el programa según la caja del modelo y el "Dónde va" que elijas; los sliders de aquí abajo son solo para afinar.
